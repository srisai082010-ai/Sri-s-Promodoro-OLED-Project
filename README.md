# Sri-s-Promodoro-OLED-Project
Pomodoro OLED Timer
About My Project
My project is a rechargeable Pomodoro Timer designed to help students and other people stay focused, manage their time, and take regular breaks. I wanted to create a useful desk device that makes studying and working more organized without constantly checking a phone. I designed the circuit schematic and PCB using KiCad and chose the XIAO ESP32-S3 microcontroller to control the timer.
How It Works
The Pomodoro Timer uses an OLED display to show the remaining work or break time. Users can rotate the rotary encoder to adjust the length of each session and press it to confirm their settings. When a session finishes, a buzzer sounds to notify the user. The timer is also designed to track completed work sessions and move the displayed digits periodically to reduce OLED burn-in.
Components
- XIAO ESP32-S3 microcontroller
- SSD1306 OLED display
- Rotary encoder with push button
- 3.3V buzzer
- 2N3904 transistor
- Resistors and capacitors
- Rechargeable 3.7V LiPo battery
- Battery connector
- Custom PCB designed in KiCad
Why I Made This Project
I created this project because I wanted a simple way to improve my productivity while studying and completing assignments. The Pomodoro technique divides work into focused sessions followed by short breaks. I also wanted to improve my electronics skills by designing a custom PCB, connecting electronic components, and learning how microcontrollers work.
Project Progress
I have designed the schematic and worked on the PCB layout and routing in KiCad. My next steps are to finish verifying the PCB, develop the firmware, assemble the components, and test the timer.
